Air Quality Monitor (AQM)

A real-time indoor air quality monitoring system built with an ESP32 microcontroller. Sensor readings are uploaded to Firebase Realtime Database every second and displayed live in this app.

Sensors Used:

  • MTP80-A (NDIR CO₂) — Measures carbon dioxide concentration (0–5000 ppm) using non-dispersive infrared absorption
  • PMS7003 (Laser PM) — Optical laser scattering sensor for PM1.0, PM2.5, PM10 particulate matter (µg/m³)
  • BME680 (Environmental) — Temperature, humidity, pressure, and VOC gas resistance via metal oxide coil. Used to compute IAQ
  • SSD1306 OLED (128×64) — Local display with 5 pages, yellow header bar, blue data body

How It Works:

The ESP32 runs a dual-core non-blocking architecture. Core 1 handles sensors, OLED, button, and buzzer in a tight loop (~1ms per iteration). Core 0 handles all Firebase HTTP uploads on a separate FreeRTOS task — so the button and display never lag.

AQI is calculated using the US EPA PM2.5 scale (0–500). IAQ combines gas resistance and humidity into a 0–500 indoor quality score. An active buzzer triggers on hazardous levels (CO₂ >1000, PM2.5 >35, AQI >100, IAQ >150).

Multi-WiFi:

The ESP32 stores up to 3 WiFi networks in NVS flash memory. On boot, it tries them in priority order. If connection drops mid-operation, Core 0 automatically reconnects. WiFi credentials can be updated remotely from this app — no need to reflash firmware.
